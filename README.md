# AI Flow Prototype

Interactive prototype for the AI-assisted trip booking flow.

## Requirements

- [Node.js](https://nodejs.org/) version 18 or higher

## Setup

1. Unzip the file and open a terminal in the project folder
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm start
   ```
4. Open your browser and go to:
   ```
   http://localhost:5173/ai-flow/home
   ```

## Prototype flow

Starting from the home page (`/ai-flow/home`), click the AI banner to enter the chat page, then submit a query to land on the results page where the full prototype is interactive.

The results page includes:
- Trip recommendations with "Ask question" and "Select trip" actions
- Seat selection chat flow
- Luggage selection chat flow
- Return trip flow
- Price breakdown accordion
