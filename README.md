# Seat Premium Zone Prototype

Interactive prototype for the seat selection flow with Premium Zone upsell.

## Requirements

- [Node.js](https://nodejs.org/) version 18 or higher

## Setup

1. Clone or unzip the project and open a terminal in the project folder
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm start
   ```
4. Open your browser and go to:
   ```
   http://localhost:5173/seat-premium-zone
   ```

## Prototype flow

The prototype covers the seat selection screen with a Premium Zone highlight panel. Users can browse the seat map, see Premium Zone seats highlighted, and interact with the upsell panel showing seat details and pricing.
